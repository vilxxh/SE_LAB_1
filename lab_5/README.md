# Lab 5 — Static Code Analysis

This folder contains the assigned Hotel Booking System program and supporting evidence for Lab 5.

## Files

- `hotel_booking_system_original.py` — untouched source copied from the assigned lab repository, used to generate baseline reports.
- `hotel_booking_system.py` — revised version with security, reliability, and style improvements.
- `issues.md` — issue log and fixes.
- `reflection.md` — reflection draft; align it with the exact four questions in the handout.
- `run_analysis.ps1` — runs Pylint, Bandit, and Flake8 and saves before/after reports.

## Run locally (Windows PowerShell)

From this folder:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install pylint bandit flake8
.un_analysis.ps1
```

The script creates six report files. Inspect the output and make sure the final results meet the lab targets. Pylint should score above 9.5/10, Bandit findings should be addressed, and Flake8 should report no violations.

## Run the revised program

```powershell
python hotel_booking_system.py
```

The program writes `hotel_ledger.txt` in the current working directory.
